# Medicinal Plant Detection

## Project Overview
Medicinal Plant Detection is a machine learning-based application designed to identify medicinal plants from images. The project uses image classification to recognize plant species and provide information about their medicinal importance.

## Features
- Medicinal plant image classification
- Image-based plant identification
- Machine learning model training
- Image dataset collection and processing
- Prediction through a Python application
- Accuracy visualization

## Technologies Used
- Python
- Machine Learning
- TensorFlow / Keras
- NumPy
- OpenCV
- Matplotlib

## Project Structure
- `app.py` – Main application
- `cnn_train.py` – Model training
- `collect_image.py` – Image collection
- `dataset.py` – Dataset processing
- `train.py` – Training script
- `accuracy_graph.png` – Accuracy visualization
- `static/` – Static files
- `templates/` – Application templates

## Purpose
The purpose of this project is to explore how machine learning and image processing can help identify medicinal plants and support learning about their potential uses.

## Disclaimer
This project is intended for educational purposes only. Plant identification predictions should not be used as a substitute for professional medical advice.
